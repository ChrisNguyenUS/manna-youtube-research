# LLM base + TikTok comment 5W1H Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the app's first LLM layer (OpenRouter) and use it for one job: a 5W1H report over collected TikTok comments, with counts done by code and every claim traceable to real comments.

**Architecture:** A `LlmClient` port with an OpenRouter adapter and a fake. Pure prompt/validate/count logic in `src/core/ai/`. One feature (`comment_5w1h` job) runs three steps: codebook from a sample, tag every comment in batches, then count in code and ask for notes and content ideas. A report route joins the saved record with the shared comment dataset; one web view picks videos and shows the result.

**Tech Stack:** Node (ES modules, JSDoc + `tsc --checkJs`), `node:test`, `node:sqlite`, global `fetch`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-16-comment-5w1h-design.md`

## Global Constraints

- No new npm dependencies. Backend has no build step.
- Layer rules of `docs/ARCHITECTURE.md` hold and `test/arch.test.js` must pass: `core/` is pure (no I/O, imports only `core/`); features never import adapters; only `src/app.js` picks adapters.
- Run tests with `npm test` (typecheck, then every `test/**/*.test.js`). A single file: `node --disable-warning=ExperimentalWarning --test test/path/file.test.js`.
- Never start a server on the real `data/` folder while verifying (the owner's app may be running and its jobs get interrupted). Use a copy: `YTR_DATA_DIR=<copy> PORT=5199`.
- Model ids are always pinned versions, never `latest` aliases. Temporary default for both models: `deepseek/deepseek-v4.1-flash-1017`.
- Limits (spec §4–5): at most 5,000 unique comments per run; codebook sample 300; batch 100; 3 batches in parallel; at most 8 groups per dimension; a dimension with under 5% tagged comments shows "không đủ dữ liệu"; at most 10 ideas; at most 3 notes per dimension; 5 example comments per group.
- OpenRouter: `POST https://openrouter.ai/api/v1/chat/completions`, timeout 120 s, at most 2 retries on 429/5xx/network error.
- Error codes: `llm_no_key`, `llm_auth`, `llm_unavailable`, `llm_bad_output`.
- User-facing text is Vietnamese, in the app's existing plain style. Code comments are English.
- `src/features/ai/knowledge/*.md` is git-ignored (paid course material); the app must run without those files.
- Commit after every task. Commit messages end with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.

## Review Focus

1. **The model answers with a label or a differently-cased key instead of the exact key** ("Người sắp phỏng vấn" for `nguoi_sap_phong_van`). Expected: still matched, not silently dropped. Test in Task 2 (`checkTags` accepts key or label, any casing/accents).
2. **The model skips comments or returns numbers that are not in the batch.** Expected: skipped comments count as "chưa phân loại", foreign numbers are ignored, nothing crashes. Test in Task 2.
3. **Comments contain newlines, `|`, or text that reads like instructions** ("bỏ qua hướng dẫn trên"). Expected: one comment stays on one prompt line and the system prompt says comments are data. Test in Task 2.
4. **The comment dataset changed after the report was saved** (video collected again with new comments; a tagged comment no longer present). Expected: the report still opens; unknown ids are skipped; new comments are simply not counted. Test in Task 3 (`report`).
5. **A model field in Settings was cleared to an empty string.** Expected: the default model is used, never an empty `model`. Test in Task 3.

`src/llm/openrouter.js`:

```js
// OpenRouter adapter of the LlmClient port. One request per call, JSON answers only.
import { aiError } from '../core/ai/base.js';
import { sleep, throwIfCancelled, rethrowIfCancelled } from '../core/cancel.js';

const URL = 'https://openrouter.ai/api/v1/chat/completions';

/**
 * @param {{getKey: () => string, fetch?: typeof globalThis.fetch, timeoutMs?: number, retries?: number, wait?: (ms: number) => Promise<any>}} o
 * @returns {import('../ports/llm.js').LlmClient}
 */
export function createOpenRouter({ getKey, fetch = globalThis.fetch, timeoutMs = 120_000, retries = 2, wait = sleep }) {
  return {
    ready: () => !!getKey(),
    async complete({ model, system, user, schema, reasoning = 'off' }) {
      const key = getKey();
      if (!key) throw aiError('llm_no_key', 'Chưa nhập API key OpenRouter. Vào Cài đặt để nhập.');
      const body = JSON.stringify({
        model,
        messages: [{ role: 'system', content: system }, { role: 'user', content: user }],
        response_format: { type: 'json_schema', json_schema: { name: 'answer', strict: true, schema } },
        // Reasoning tokens are billed as output: off for bulk tagging, low where the model has to write.
        reasoning: reasoning === 'low' ? { effort: 'low' } : { enabled: false },
        usage: { include: true },
      });
      for (let attempt = 0; ; attempt++) {
        throwIfCancelled();
        const last = attempt >= retries;
        let res;
        try {
          res = await fetch(URL, { method: 'POST', headers: { authorization: `Bearer ${key}`, 'content-type': 'application/json' }, body, signal: AbortSignal.timeout(timeoutMs) });
        } catch (e) {
          rethrowIfCancelled(e);
          if (last) throw aiError('llm_unavailable', `Không gọi được OpenRouter: ${e?.message || e}`);
          await wait(1000 * 2 ** attempt);
          continue;
        }
        if (res.status === 401 || res.status === 403) throw aiError('llm_auth', 'API key OpenRouter không đúng. Kiểm tra lại trong Cài đặt.');
        if (res.status === 429 || res.status >= 500) {
          if (last) throw aiError('llm_unavailable', `OpenRouter đang lỗi (HTTP ${res.status}). Thử lại sau.`);
          await wait(1000 * 2 ** attempt);
          continue;
        }
        if (!res.ok) throw aiError('llm_unavailable', `OpenRouter từ chối yêu cầu (HTTP ${res.status}): ${(await res.text()).slice(0, 200)}`);
        const data = /** @type {any} */ (await res.json());
        let json;
        try {
          json = JSON.parse(data.choices?.[0]?.message?.content ?? '');
        } catch {
          throw aiError('llm_bad_output', 'AI trả lời không đúng định dạng JSON');
        }
        const u = data.usage ?? {};
        return { json, model: data.model ?? model, tokensIn: u.prompt_tokens ?? 0, tokensOut: u.completion_tokens ?? 0, costUsd: typeof u.cost === 'number' ? u.cost : null };
      }
    },
  };
}
```

```js
// Scripted LlmClient for tests: no network, records every request.

/**
 * @param {any[] | ((req: import('../ports/llm.js').LlmRequest, index: number) => any)} script
 *   replies in call order, or a function of the request; a reply that is an Error is thrown
 * @param {{ready?: boolean}} [o]
 * @returns {import('../ports/llm.js').LlmClient & {calls: import('../ports/llm.js').LlmRequest[]}}
 */
export function createFakeLlm(script = [], { ready = true } = {}) {
  /** @type {import('../ports/llm.js').LlmRequest[]} */
  const calls = [];
  return {
    calls,
    ready: () => ready,
    async complete(req) {
      calls.push(req);
      const next = typeof script === 'function' ? script(req, calls.length - 1) : script.shift();
      if (next instanceof Error) throw next;
      if (next === undefined) throw new Error('fake llm: no reply left');
      return { json: structuredClone(next), model: req.model, tokensIn: 10, tokensOut: 5, costUsd: 0.25 };
    },
  };
}
```

```js
/** @typedef {Record<string, string|null>} Tags */

/**
 * What gets sent: comments with words, not from sellers, identical text once (its copies share the result),
 * most noticed first, at most `limit`. Numbers (n) stand in for TikTok ids in prompts.
 * @param {any[]} comments @param {number} [limit]
 * @returns {{items: Item[], sent: number, dropped: number}} sent/dropped count comments, copies included
 */
export function prepare(comments, limit = LIMITS.comments) {
  const seen = new Map();
  for (const c of comments || []) {
    if (!hasWords(c.text) || isSeller(c.text)) continue;
    const key = fold(c.text);
    const it = seen.get(key);
    if (it) (it.ids.push(String(c.id)), (it.score += voiceScore(c)));
    else seen.set(key, { text: String(c.text).trim().slice(0, 500), parentText: c.parentText ? String(c.parentText).slice(0, 200) : '', ids: [String(c.id)], score: voiceScore(c) });
  }
  const all = [...seen.values()].sort((a, b) => b.score - a.score || (a.ids[0] < b.ids[0] ? -1 : 1));
  const count = (l) => l.reduce((s, it) => s + it.ids.length, 0);
  const items = all.slice(0, limit).map((it, i) => ({ n: i + 1, ...it }));
  return { items, sent: count(items), dropped: count(all.slice(limit)) };
}

export function estimateOf(prep) {

  return { comments: prep.sent, unique: prep.items.length, dropped: prep.dropped, tokens: Math.ceil(chars / 3) };
}

/** @param {any} json @returns {Codebook} */
export function checkCodebook(json) {
  /** @type {Codebook} */
  const out = {};
  let total = 0;
  for (const d of DIMS) {
    const seen = new Set();
    out[d] = [];
    for (const g of list(json?.[d])) {
      const key = slug(g?.key || g?.label);

/**
 * Rows the batch really asked for, with keys that exist (matched by key or label, any casing or accents).
 * @param {any} json @param {Codebook} codebook @param {Item[]} batch
 * @returns {{byN: Map<number, Tags>, bad: number}} bad: rows and keys that had to be thrown away
 */
export function checkTags(json, codebook, batch) {
  const asked = new Set(batch.map((it) => it.n));
  const keyOf = Object.fromEntries(DIMS.map((d) => [d, new Map(codebook[d].flatMap((g) => [[g.key, g.key], [slug(g.label), g.key]]))]));
  const byN = new Map();
  let bad = 0;
  for (const row of list(json?.tags)) {
    const n = Number(row?.n);
    if (!row || typeof row !== 'object' || !asked.has(n) || byN.has(n)) {
      bad++;
      continue;
    }
    /** @type {Tags} */
    const t = {};
    for (const d of DIMS) {
      const want = row[d] == null ? '' : slug(row[d]);
      t[d] = keyOf[d].get(want) ?? null;
      if (want && !t[d]) bad++;
    }
    byN.set(n, t);
  }
  if (!byN.size) throw aiError('llm_bad_output', 'AI không gắn được nhóm cho lô bình luận này');
  return { byN, bad };
}

/** Tags per comment id: every copy of a merged comment gets the result of its text. @param {Item[]} items @param {Map<number, Tags>} byN */
export function expandTags(items, byN) {
  /** @type {Record<string, Tags>} */
  const out = {};
  for (const it of items) {
    const t = byN.get(it.n);
    if (t) for (const id of it.ids) out[id] = t;
  }
  return out;
}

/**
 * The counting: per dimension, its groups with how many tagged comments fall in each (largest first) and their ids
 * (most noticed first). Comments without tags, or tags of comments that are gone, are not counted.
 * @param {Codebook} codebook @param {Record<string, Tags>} tags @param {any[]} comments
 */
export function tally(codebook, tags, comments) {
  const rows = (comments || []).filter((c) => tags[String(c.id)]).sort((a, b) => voiceScore(b) - voiceScore(a) || (String(a.id) < String(b.id) ? -1 : 1));
  /** @type {Record<string, {tagged: number, share: number, enough: boolean, groups: {key: string, label: string, description: string, count: number, ids: string[]}[]}>} */
  const dims = {};
  for (const d of DIMS) {
    const groups = codebook[d].map((g) => {
      const ids = rows.filter((c) => tags[String(c.id)][d] === g.key).map((c) => String(c.id));
      return { ...g, count: ids.length, ids };
    }).filter((g) => g.count).sort((a, b) => b.count - a.count);
    const tagged = groups.reduce((s, g) => s + g.count, 0);
    const share = rows.length ? tagged / rows.length : 0;
    dims[d] = { tagged, share, enough: share >= LIMITS.minShare, groups };
  }
  return { total: rows.length, dims };
}

 * A note or idea left without evidence is dropped. @param {any} json @param {Codebook} codebook @param {string[]} refs
 */
export function checkSummary(json, codebook, refs) {
  let bad = 0;
  const text = (v) => (typeof v === 'string' && v.trim() ? v.trim() : null);
  const ids = (v) => {
    const got = list(v).map((n) => refs[Number(n) - 1]);
    bad += got.filter((x) => !x).length;
    return [...new Set(got.filter(Boolean))];
  };
  const keysIn = (d) => new Map(codebook[d].flatMap((g) => [[g.key, g.key], [slug(g.label), g.key]]));
  /** @type {Record<string, {text: string, keys: string[]}[]>} */
  const notes = {};
  for (const d of DIMS) {
    const known = keysIn(d);
    notes[d] = [];
    for (const x of list(json?.notes?.[d])) {
      const all = list(x?.keys).map((k) => known.get(slug(k)));
      bad += all.filter((k) => !k).length;
      const keys = [...new Set(all.filter(Boolean))];
      if (!text(x?.text) || !keys.length) {
        if (text(x?.text)) bad++;
        continue;
      }
      if (notes[d].length < LIMITS.notes) notes[d].push({ text: /** @type {string} */ (text(x.text)), keys: /** @type {string[]} */ (keys) });
    }
  }
  const who = keysIn('who');
  const ideas = [];
  for (const x of list(json?.ideas)) {
    const evidence = ids(x?.evidence);
    const beliefEvidence = x?.belief ? ids(x.belief.evidence) : [];
    if (!text(x?.title) || !evidence.length) {
      if (text(x?.title)) bad++;
      continue;
    }
    if (x?.who != null && !who.get(slug(x.who))) bad++;
    if (x?.funnel != null && !FUNNEL.includes(x.funnel)) bad++;
    if (x?.belief && !beliefEvidence.length) bad++;
    ideas.push({
      title: text(x.title), who: who.get(slug(x?.who)) ?? null, pain: text(x?.pain),
      belief: text(x?.belief?.text) && beliefEvidence.length ? { text: text(x.belief.text), evidence: beliefEvidence } : null,
      concept: text(x?.concept), extraConcepts: list(x?.extraConcepts).map(text).filter(Boolean).slice(0, 2),
      funnel: FUNNEL.includes(x?.funnel) ? x.funnel : null, evidence,
    });
  }
  return { notes, ideas: ideas.slice(0, LIMITS.ideas), bad };
}
```

```js
// Use case: 5W1H report over collected TikTok comments, written with a language model (spec 2026-11-16).
// Three steps: groups from a sample, every comment assigned in batches, then counting in code and one call for
// notes and content ideas. A failed batch leaves its comments "chưa phân loại"; a failed summary still saves the counts.
import { noop } from '../shared.js';
import { rethrowIfCancelled } from '../../core/cancel.js';
import { aiError, DEFAULT_MODEL } from '../../core/ai/base.js';
import { LIMITS, prepare, estimateOf, codebookRequest, checkCodebook, tagRequest, checkTags, expandTags, tally, summaryRequest, checkSummary } from '../../core/ai/five-w.js';

const KIND = 'comment_5w1h';
const PARALLEL = 3;
/** Errors no retry can fix: stop the whole job. */
const FATAL = new Set(['llm_auth', 'llm_no_key']);
const invalid = (message, field) => Object.assign(new Error(message), { code: 'invalid_input', field });
const idsOf = (videos) => [...new Set(String(videos || '').split(/[\s,]+/).filter((x) => /^\d{15,25}$/.test(x)))].slice(0, 200);
const chunk = (list, size) => Array.from({ length: Math.ceil(list.length / size) }, (_, i) => list.slice(i * size, (i + 1) * size));
const modelOf = (v) => String(v || '').trim() || DEFAULT_MODEL;
const addCost = (a, b) => (a == null || b == null ? null : a + b);

/** Run fn over the list, `size` at a time. An error from fn stops everything. */
async function pool(list, size, fn) {
  let next = 0;
  await Promise.all(Array.from({ length: Math.min(size, list.length) }, async () => {
    while (next < list.length) await fn(list[next++]);
  }));
}

/**
 * @param {{llm: import('../../ports/llm.js').LlmClient, readComments: (ids: string[]) => {videos: any[], comments: any[]},
 *   records: {add: Function, get: Function, update: Function}, settings: () => Record<string, any>, knowledge?: string, batchSize?: number}} deps
 *   knowledge: the course notes given to the summary step ('' when the files are missing)
 */
export function makeComment5w1h({ llm, readComments, records, settings, knowledge = '', batchSize = LIMITS.batch }) {
  /** Counts calls, tokens and money of one job. */
  function meter() {
    const usage = { calls: 0, tokensIn: 0, tokensOut: 0, costUsd: /** @type {number|null} */ (0) };
    return {
      usage,
      async ask(req, model) {
        usage.calls++; // counted before the call: a failed call was still made
        const r = await llm.complete({ ...req, model });
        usage.tokensIn += r.tokensIn;
        usage.tokensOut += r.tokensOut;
        usage.costUsd = addCost(usage.costUsd, r.costUsd);
        return r.json;
      },
    };
  }

  /** One retry for anything a second try can fix (bad output, a busy provider). */
  async function twice(fn) {
    try {
      return await fn();
    } catch (e) {
      rethrowIfCancelled(e);
      if (FATAL.has(e?.code)) throw e;
      return fn();
    }
  }

  async function write(m, codebook, tags, comments, model) {
    const { request, refs } = summaryRequest(tally(codebook, tags, comments), comments, knowledge);
    return checkSummary(await m.ask(request, model), codebook, refs);
  }

  async function rewrite(id, progress) {
    const rec = records.get(id);
    if (!rec || rec.kind !== KIND) throw Object.assign(new Error('Không thấy báo cáo 5W1H'), { code: 'not_found' });
    const d = rec.data;
    const model = modelOf(settings().aiWriteModel);
    const m = meter();
    progress({ step: 'Tổng hợp', done: 0, total: 1 });
    const sum = await twice(() => write(m, d.codebook, d.tags, readComments(d.videoIds).comments, model));
    records.update(id, {
      ...d, notes: sum.notes, ideas: sum.ideas, summaryError: null, hasKnowledge: !!knowledge, counts: { ...d.counts, badRefs: sum.bad },
      usage: { ...d.usage, writeModel: model, calls: d.usage.calls + m.usage.calls, tokensIn: d.usage.tokensIn + m.usage.tokensIn, tokensOut: d.usage.tokensOut + m.usage.tokensOut, costUsd: addCost(d.usage.costUsd, m.usage.costUsd) },
    });
    return { id };
  }

  /** @param {{videos?: string, onlyStep3?: number}} params @param {(p: any) => void} [progress] progress throws once the job is cancelled */
  async function run(params, progress = noop) {
    if (!llm.ready()) throw aiError('llm_no_key', 'Chưa nhập API key OpenRouter. Vào Cài đặt để nhập.');
    if (params.onlyStep3) return rewrite(Number(params.onlyStep3), progress);
    const videoIds = idsOf(params.videos);
    if (!videoIds.length) throw invalid('Chọn ít nhất một video', 'videos');
    const { comments } = readComments(videoIds);
    const prep = prepare(comments);
    if (!prep.items.length) throw invalid('Không có comment nào có chữ', 'videos');
    const s = settings();
    const [tagModel, writeModel] = [modelOf(s.aiTagModel), modelOf(s.aiWriteModel)];
    const m = meter();

    progress({ step: 'Lập bảng mã', done: 0, total: 1 });
    const codebook = await twice(async () => checkCodebook(await m.ask(codebookRequest(prep.items.slice(0, LIMITS.sample)), tagModel)));

    const batches = chunk(prep.items, batchSize);
    const byN = new Map();
    let done = 0;
    let failedBatches = 0;
    let badTags = 0;
    progress({ step: 'Gắn mã', done: 0, total: batches.length });
    await pool(batches, PARALLEL, async (batch) => {
      try {
        const r = await twice(async () => checkTags(await m.ask(tagRequest(codebook, batch), tagModel), codebook, batch));
        for (const [n, t] of r.byN) byN.set(n, t);
        badTags += r.bad;
      } catch (e) {
        rethrowIfCancelled(e);
        if (FATAL.has(e?.code)) throw e;
        failedBatches++;
      }
      progress({ step: 'Gắn mã', done: ++done, total: batches.length });
    });
    const tags = expandTags(prep.items, byN);
    const tagged = Object.keys(tags).length;
    if (!tagged) throw aiError('llm_unavailable', 'AI không gắn được nhóm cho lô bình luận nào. Thử lại, hoặc đổi model trong Cài đặt.');

    progress({ step: 'Tổng hợp', done: 0, total: 1 });
    /** @type {{notes: any, ideas: any, summaryError: string|null, bad: number}} */
    let sum;
    try {
      sum = { ...(await twice(() => write(m, codebook, tags, comments, writeModel))), summaryError: null };
    } catch (e) {
      rethrowIfCancelled(e);
      sum = { notes: null, ideas: null, summaryError: String(e?.message || e), bad: 0 }; // the counts are still worth keeping
    }
    const data = {
      videoIds, counts: { sent: prep.sent, tagged, untagged: prep.sent - tagged, dropped: prep.dropped, failedBatches, badTags, badRefs: sum.bad },
      codebook, tags, notes: sum.notes, ideas: sum.ideas, summaryError: sum.summaryError, hasKnowledge: !!knowledge,
      usage: { tagModel, writeModel, ...m.usage },
    };
    return { id: records.add(KIND, `${videoIds.length} video · ${prep.sent} comment`, { params, data }) };
  }

  /** How much a run on these videos would send. @param {string} videos */
  function estimate(videos) {
    const ids = idsOf(videos);
    return { ...estimateOf(prepare(ids.length ? readComments(ids).comments : [])), ready: llm.ready() };
  }

  /** A saved report with today's comments of its videos: the counted table, and each comment with its tags (w). @param {number} id */
  function report(id) {
    const rec = records.get(id);
    if (!rec || rec.kind !== KIND) throw Object.assign(new Error('Không thấy báo cáo 5W1H'), { code: 'not_found' });
    const { videos, comments } = readComments(rec.data.videoIds);
    return {
      id: rec.id, title: rec.title, createdAt: rec.created_at, data: rec.data, videos,
      table: tally(rec.data.codebook, rec.data.tags, comments),
      comments: comments.map((c) => ({ ...c, w: rec.data.tags[String(c.id)] ?? null })),
    };
  }

  return { run, estimate, report };
}
```

```js
// Markdown of a 5W1H report, complete enough to hand to Claude without opening the app.
import { DIMS, DIM_INFO } from '../ai/five-w.js';

const FUNNEL_LABELS = { biet: 'Biết', thich: 'Thích', tin: 'Tin', yeu: 'Yêu' };
const num = (n) => Number(n || 0).toLocaleString('vi-VN');
const PER_GROUP = 8;

/** @param {{title: string, createdAt: number, videos: any[], comments: any[], table: any, data: any}} r the object features.comment5w1h.report() returns */
export function fiveWMarkdown(r) {
  const d = r.data;
  const byId = new Map(r.comments.map((c) => [String(c.id), c]));
  const quote = (id) => (byId.has(id) ? `"${String(byId.get(id).text).replace(/\s+/g, ' ').trim()}"` : null);
  const quotes = (ids) => ids.map(quote).filter(Boolean).join(' · ');
  const label = (dim, key) => d.codebook[dim].find((g) => g.key === key)?.label ?? key;
  const u = d.usage;
  const out = [
    `# 5W1H comment TikTok: ${r.title}`,
    '',
    `${num(r.table.total)} comment đã xếp nhóm${d.counts.untagged ? `, ${num(d.counts.untagged)} chưa phân loại` : ''}${d.counts.dropped ? `, ${num(d.counts.dropped)} bị bỏ vì vượt giới hạn` : ''}. Ngày ${new Date(r.createdAt).toISOString().slice(0, 10)}.`,
    `Nhận định do AI viết, số đếm do app tính. Model gắn mã: ${u.tagModel}. Model tổng hợp: ${u.writeModel}. ${num(u.tokensIn + u.tokensOut)} token${u.costUsd == null ? '' : `, $${u.costUsd.toFixed(4)}`}.`,
    '',
    '## Video',
    ...r.videos.map((v) => `- ${v.caption || v.url}${v.author ? ` (@${v.author})` : ''}: ${v.url}`),
  ];
  if (!d.notes) out.push('', `> AI chưa viết được phần nhận định và gợi ý (${d.summaryError || 'không rõ lỗi'}). Các nhóm và số đếm bên dưới vẫn đúng.`);
  for (const dim of DIMS) {
    const t = r.table.dims[dim];
    out.push('', `## ${DIM_INFO[dim][0]}: ${DIM_INFO[dim][1]}`, '');
    if (!t.enough) {
      out.push('Không đủ dữ liệu: bình luận gần như không nói về chiều này.');
      continue;
    }
    const notes = d.notes?.[dim] ?? [];
    if (notes.length) out.push(...notes.map((n) => `- ${n.text}`), '');
    for (const g of t.groups) {
      out.push(`### ${g.label} (${num(g.count)} comment)`);
      out.push(...g.ids.slice(0, PER_GROUP).map((id) => { const c = byId.get(id); return `- "${String(c.text).replace(/\s+/g, ' ').trim()}" (${num(c.likes)} tim, ${num(c.replies)} trả lời)`; }), '');
    }
    if (out.at(-1) === '') out.pop();
  }
  if (d.ideas?.length) {
    out.push('', '## Gợi ý content', '', 'Các gợi ý này dựa trên nỗi đau trong comment. Chưa đối chiếu với video đã thắng.');
    d.ideas.forEach((x, i) => {
      out.push('', `### ${i + 1}. ${x.title}`);
      if (x.who) out.push(`- Ai: ${label('who', x.who)}`);
      if (x.pain) out.push(`- Nỗi đau: ${x.pain}`);
      if (x.belief) out.push(`- Đang tin: ${x.belief.text}${quotes(x.belief.evidence) ? ` (${quotes(x.belief.evidence)})` : ''}`);
      if (x.concept) out.push(`- Concept: ${x.concept}${x.extraConcepts.length ? ` (phụ: ${x.extraConcepts.join(', ')})` : ''}`);
      if (x.funnel) out.push(`- Phễu: ${FUNNEL_LABELS[x.funnel]}`);
      out.push('- Chưa có tiền lệ outlier');
      if (quotes(x.evidence)) out.push(`- Bằng chứng: ${quotes(x.evidence)}`);
    });
  }
  return out.join('\n') + '\n';
}
```

```js
//   cp -R data /tmp/ytr-try && YTR_DATA_DIR=/tmp/ytr-try npm run llm:try -- 7000…001,7000…002 deepseek/deepseek-v4.1-flash-1017 z-ai/glm-5.3-flash
import fs from 'node:fs';
import path from 'node:path';
import { createApp } from '../src/app.js';
import { ROOT } from '../src/config.js';
import { makeComment5w1h } from '../src/features/ai/comment-5w1h.js';
import { fiveWMarkdown } from '../src/core/report/five-w.js';

const [videos, ...models] = process.argv.slice(2);
if (!videos || !models.length) {
  console.error('Cách dùng: npm run llm:try -- <id video, cách nhau bằng dấu phẩy> <model> [<model>…]');
  process.exit(2);
}
const app = createApp();
if (path.resolve(app.config.dataDir) === path.join(ROOT, 'data')) {
  console.error('Đang trỏ vào thư mục data thật. Chạy trên bản sao: cp -R data /tmp/ytr-try && YTR_DATA_DIR=/tmp/ytr-try npm run llm:try -- …');
  process.exit(2);
}
if (!app.llm.ready()) {
  console.error('Chưa có API key OpenRouter trong Cài đặt của thư mục dữ liệu này.');
  process.exit(2);
}
const readComments = (ids) => app.features.commentData.comments(ids);
const knowledge = fs.existsSync(path.join(ROOT, 'src/features/ai/knowledge')) ? fs.readdirSync(path.join(ROOT, 'src/features/ai/knowledge')).filter((f) => f.endsWith('.md')).sort().map((f) => fs.readFileSync(path.join(ROOT, 'src/features/ai/knowledge', f), 'utf8')).join('\n\n---\n\n') : '';
const rows = [];
const parts = [];
for (const model of models) {
  const saved = new Map();
  const records = { add: (kind, title, o) => (saved.set(1, { id: 1, kind, title, created_at: Date.now(), ...o }), 1), get: (id) => saved.get(id), update: (id, data) => void (saved.get(id).data = data) };
  const f = makeComment5w1h({ llm: app.llm, readComments, records, knowledge, settings: () => ({ aiTagModel: model, aiWriteModel: model }) });
  const t0 = Date.now();
  try {
    await f.run({ videos }, (p) => process.stdout.write(`\r${model}: ${p.step} ${p.done ?? ''}/${p.total ?? ''}   `));
    const r = f.report(1);
    const c = r.data.counts;
    rows.push({ model, 'giây': Math.round((Date.now() - t0) / 1000), 'gửi': c.sent, 'gắn được %': Math.round((c.tagged / c.sent) * 100), 'lô lỗi': c.failedBatches, 'mã sai': c.badTags, 'dẫn sai': c.badRefs, 'gợi ý': r.data.ideas?.length ?? 0, token: r.data.usage.tokensIn + r.data.usage.tokensOut, usd: r.data.usage.costUsd, 'tổng hợp': r.data.summaryError ? `lỗi: ${r.data.summaryError}` : 'ok' });
    parts.push(`<!-- ===== ${model} ===== -->\n\n${fiveWMarkdown({ ...r, title: `${model} · ${r.title}` })}`);
  } catch (e) {
    rows.push({ model, 'giây': Math.round((Date.now() - t0) / 1000), 'tổng hợp': `hỏng: ${e.code || ''} ${e.message}` });
  }
  process.stdout.write('\n');
}
console.table(rows);
fs.mkdirSync(path.join(ROOT, 'output'), { recursive: true });
const file = path.join(ROOT, 'output', `llm-try-${new Date().toISOString().replace(/[:.]/g, '-')}.md`);
fs.writeFileSync(file, parts.join('\n\n---\n\n'));
console.log(`Đọc và so các báo cáo ở: ${file}`);
await app.close();
```
